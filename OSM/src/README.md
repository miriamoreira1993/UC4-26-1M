# O Senhor dos Mercados II

## Sobre o projeto

O Senhor dos Mercados II é um RPG desenvolvido em TypeScript, no qual o jogador escolhe um herói para enfrentar inimigos das Redes Alfa e Ômega.

O objetivo é vencer as batalhas, derrotar o chefe final Balrog do Boleto e chegar ao Servidor da Perdição.

## Instalação

Para instalar as dependências, execute:

```bash
npm install
npm install readline-sync
npm install --save-dev @types/readline-sync
```

## Como executar

Para iniciar o jogo, execute no terminal:

```bash
npm start
```

## Estrutura do projeto

- src/classes: contém as classes dos personagens e heróis.
- src/interfaces: contém as interfaces do projeto.
- src/index.ts: contém o menu principal e a execução do jogo.
- README.md: documentação do projeto.

## Conceitos utilizados

- Classes e objetos
- Herança
- Encapsulamento
- Polimorfismo
- Interfaces
- Arrays
- Estruturas condicionais
- Laços de repetição
- Combate por turnos

## Objetivo

Desenvolver um RPG interativo utilizando os conceitos de Programação Orientada a Objetos com TypeScript.
